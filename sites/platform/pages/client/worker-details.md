# Worker Details

View and manage individual worker information.

## Routes

- `/organisations/:orgId/workers/:id/:route` - Worker detail tabs
- `/organisations/:orgId/workers/:id/employee-work-offer` - Send new work offer

## Features

- Personal details view
- Contract and engagement history
- Document access
- Expense and timesheet review
- HR modification actions at `/organisations/:orgId/workers/:id/hr-modify-engagements/:action`
