# Create Offer

Create new employment or contractor offers.

## Routes

- `/organisations/:organisationId/create-eorinstance` - Select engagement type
- `/organisations/:organisationId/create-eorinstance/employee` - Employee offer form
- `/organisations/:organisationId/create-eorinstance/contractor` - Contractor offer form

## Features

- Country and currency selection
- Job title and salary entry
- Start date and employment type
- Benefits configuration
- Cost preview
