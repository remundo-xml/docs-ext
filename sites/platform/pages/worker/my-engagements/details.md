# Engagement Details

View organisation, team, and submission configuration for a specific engagement.

## Route

`/my-engagements/:id/details`

## Overview

The details view shows expandable accordion sections for the selected engagement.

## Organisation details

- Billing entity name
- Worker type
- Role title
- Role location (country name with flag)
- Start date
- End date (or "Open-Ended" when not set)

## Line managers and team

- Line managers displayed as an avatar list with hover tooltips showing name and job title
- Assigned team name (or "Unassigned" when no team is set)

## Timesheets

- Submission requirement (required or not required)
- Overtime submission (allowed or not allowed)
- First level approvers
- Second level approvers

## Expenses

- Submission permission (permitted or not permitted)
- First level approvers
- Second level approvers

## Absences

- Submission permission (permitted or not permitted)
- First level approvers
- Second level approvers

Multi-level approvers are shown for each section where applicable.
